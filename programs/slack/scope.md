# Slack Security
## In Scope
- slack.com web application
- Slack mobile apps
- Slack desktop apps
- Slack API

## Rewards
- RCE: up to $20,000
- Auth bypass: up to $10,000
- XSS: up to $5,000
- CSRF: up to $5,000
- SSRF: up to $5,000

## Quick Targets
1. Slack app OAuth flows
2. Workspace redirect URLs
3. Message link injection
