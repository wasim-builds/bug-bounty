# GitHub Security
## In Scope
- github.com web application
- GitHub mobile apps
- GitHub Desktop
- GitHub Actions
- GitHub Pages
- Public repos on github.com

## Rewards
- RCE: up to $25,000
- SSRF: up to $15,000
- Auth bypass: up to $10,000
- XSS: up to $5,000
- Info disclosure: up to $5,000

## Quick Targets
1. GitHub Actions workflow injection
2. Pages SSRF via custom domains
3. OAuth token leakage in repos
